# {{PROJECT}}: 제7의 뇌 연결 (이 폴더 아래 모든 워크트리)

누적 지식은 Obsidian 볼트 `{{VAULT}}`에 있다.

## 작업 시작 전
- 코드나 설정을 바꾸는 작업이면 먼저 프로젝트 첫 페이지 `{{VAULT}}\01_Projects\{{PROJECT}}\_index.md`를 읽는다 (목적, 결정, 최근 진행). 볼트에서 폴더 이름을 바꿨다면 tags에 `{{PROJECT}}`가 있는 `_index.md`를 찾는다.
- 이어서 하는 작업이면 `{{VAULT}}\03_Daily\`의 가장 최근 데일리 노트도 확인한다.
- `{{VAULT}}\99_Private\`는 열지 않는다.

## 작업 중
- 되돌리기 어렵거나 이유가 중요한 설계 결정은 프로젝트 폴더의 `decisions\<무엇을 정했는지>.md`에 남긴다. 파일 이름에 날짜는 넣지 않는다 (날짜는 프런트매터 created). 내용은 맥락, 결정, 이유, 버린 대안, source: claude.
- 작업 기록, 데일리 노트, 프로젝트 첫 페이지의 최근 진행은 매일 밤 자동으로 갱신되므로 따로 정리하지 않는다.
