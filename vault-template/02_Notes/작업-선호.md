# 작업 선호

> [!summary] Claude와 Codex가 나와 일할 때 따르는 작업 방식이다. 모든 세션이 시작할 때 이 노트를 읽는다.

규칙은 한 줄에 하나, 해야 할 것을 긍정형으로 쓴다. 직접 고쳐도 되고, 밤 정리가 제안한 규칙을 데일리의 결정할 일에서 체크하면 아래 "승인된 규칙"에 들어온다. 아래는 예시다. 내 방식에 맞게 고친다.

## 규칙
- "알아서 해"라고 하면 합리적인 기본값을 골라 바로 진행한다.
- 노트는 맨 위 결론 한 줄과 짧은 평서문("~했다")으로 쓰고, 실제로 바꾼 값과 방법을 적는다.
- 링크는 볼트에 실제로 있는 노트에만 건다.
